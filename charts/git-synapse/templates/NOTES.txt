Git Synapse {{ .Chart.AppVersion }} is installed.

Sign in as {{ .Values.secrets.adminEmail }}. Its password is in the Kubernetes
Secret:
  {{ include "git-synapse.secretName" . }}

Read it with:
  kubectl -n {{ .Release.Namespace }} get secret {{ include "git-synapse.secretName" . }} -o jsonpath='{.data.ADMIN_PASSWORD}' | base64 -d; echo

The account is created every time the API starts, so changing the password in
the Secret and restarting is also how you reset a forgotten one. Add other
people from the People page once you are in.

{{- if .Values.ingress.enabled }}
Open the configured Ingress URL:
  {{- range .Values.ingress.hosts }}
  https://{{ .host }}
  {{- end }}
{{- else }}
For a temporary local connection:
  kubectl -n {{ .Release.Namespace }} port-forward service/{{ include "git-synapse.fullname" . }} 8080:{{ .Values.service.port }}
Then open: http://localhost:8080
{{- end }}

Check rollout status:
  kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "git-synapse.fullname" . }}-api
